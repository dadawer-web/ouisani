# 简单番茄钟 Web 应用

这是一个极其简单的番茄钟 Web 应用，帮助您专注工作。

## 功能特性

- ⏰ 25分钟工作时间（可自定义）
- 🌿 5分钟休息时间（可自定义）
- 📊 进度条显示
- 🍅 完成番茄钟计数
- 🔊 完成提醒音效
- 💾 本地存储已完成次数

## 使用方法

1. 直接在浏览器中打开 `index.html` 文件
2. 点击「开始」按钮开始番茄钟
3. 使用「暂停」按钮暂停计时
4. 使用「重置」按钮重置计时器
5. 在设置区域可以自定义工作/休息时间

## 文件结构

```
frontend/
├── index.html      # 主页面
├── styles.css      # 样式文件
├── app.js          # 应用逻辑
└── README.md       # 说明文档
```

## 自定义设置

- **工作时间**: 默认25分钟，可在1-60分钟之间调整
- **休息时间**: 默认5分钟，可在1-30分钟之间调整

## 本地运行

由于这是一个纯前端应用，您可以：

1. 直接双击 `index.html` 文件
2. 或使用简单的HTTP服务器：
   ```bash
   # 使用Python 3
   python3 -m http.server 8000
   
   # 然后访问 http://localhost:8000
   ```

## 浏览器兼容性

- Firefox 40+
- Safari 10+
- Edge 12+

## 技术说明

- 使用原生HTML5、CSS3和JavaScript
- 无外部依赖
- 使用localStorage保存数据
- 使用Web Audio API播放提示音
