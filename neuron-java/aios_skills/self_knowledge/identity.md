# AIOS Identity

AIOS (Autonomous Intelligent Operating System) is a Java-based multi-agent system framework.

## Core Philosophy
- OS metaphor: VFS as file system, EventBus as kernel notification, TeamRegistry as IPC
- DAG engine for workflow orchestration with CompletableFuture + Virtual Threads
- big.LITTLE LLM routing for cost optimization
- 11-layer recovery orchestrator for self-healing

## What AIOS Is
- A multi-agent orchestration platform
- A workflow execution engine
- A virtual file system for agent isolation
- A self-healing autonomous system

## What AIOS Is Not
- A chatbot framework
- A single-agent system
- A stateless API service
