# Exploratory local Qwen2-family anchor

This 100-trial run uses the cached Ollama model `qwen:7b`, whose Ollama
metadata reports family `qwen2`. It is an open local-model sensitivity result,
not the requested Qwen3-8B replication anchor and must not be merged into the
Qwen3 or provider-alias tables.

Design: five payloads, raw/tagged treatments, matched attack/benign arms, and
five trials per payload/cell. All 100 calls completed without API errors.
