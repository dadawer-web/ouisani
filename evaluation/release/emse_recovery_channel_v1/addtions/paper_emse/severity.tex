\section{RQ2: Native Recovery-Path Exploitability}
\label{sec:severity}

Attack success is defined by a canary behavior in the native framework
artifact or model response. Matched benign controls use the same task and
recovery structure without the injected directive. We report framework,
model, and payload strata rather than relying on a single pooled ASR.

\paragraph{Fixed local open-model sensitivity anchor.}
The cached local \QwenLocalModel{} was run through the same pinned Reflexion
generator as a sensitivity check.  With \QwenLocalTrialsPerCell{} trials per
payload/cell, the raw treatment produced
\QwenLocalRawSuccesses{}/\QwenLocalAttackTrials{} attack successes
(\QwenLocalRawASR{}), while TrustOrigin framing produced
\QwenLocalTaggedSuccesses{}/\QwenLocalAttackTrials{}
(\QwenLocalTaggedASR{}).  Both matched benign FPRs were zero and the Fisher
contrast was $p=\QwenLocalFisherP{}$.  Because this is a 100-trial exploratory
anchor rather than a powered mitigation comparison, it is not pooled with
the canonical provider-alias matrix.

\subsection{Native Reflexion TrustOrigin Port}
\label{sec:reflexion-trustorigin-native}

generator at the same commit. With \NativeTrustOriginModel{}, five payloads,
and \NativeTrustOriginTrialsPerCell{} trials per payload, arm, and treatment,
the raw recovery treatment produced
\NativeTrustOriginRawSuccesses{}/\NativeTrustOriginAttackTrials{}

\NativeTrustOriginRawFPR{} and \NativeTrustOriginTaggedFPR{}, respectively;

\subsection{Native AutoGen Recovery/Error Flow}
\label{sec:autogen-e2e}

\texttt{AssistantAgent}, \texttt{FunctionTool}, tool-error event, and
subsequent recovery turn. With \AutoGenTrialsPerVariantArm{} trials per

\subsection{Native Aider Recovery/Error Flow}
\label{sec:aider-e2e}

Aider \texttt{v0.86.2} was executed through
\texttt{aider.coders.base\_coder.Coder.run\_one}, its native
\texttt{cmd\_test} non-zero output, and the same Coder recovery loop. GPT-5.6
Luna yielded \AiderGptASR{} attack ASR and \AiderGptPathRate{} native path
completion, with zero benign successes. The native transcript records the
test failure being added to the live conversation before the recovery turn;
the result is therefore not a message-format reconstruction.

\subsection{Mechanism and Channel Screen}
\label{sec:recova-testbed}

The Reflexion message-level Kimi K2.6 screen uses 20 trials per payload, arm,
and cell. The recovery/raw user-tail reference is \CausalRawRecoveryASR{};
the tagged variant is \CausalTaggedRecoveryASR{}; the forward/raw user-tail
cell is \CausalForwardASR{}; the system-tail and user-head recovery cells are
\CausalSystemTailASR{} and \CausalUserHeadASR{}, respectively. Every benign
cell has zero FPR. The raw-versus-tagged difference is small, so this result
is mechanism screening rather than a confirmatory estimate.

\subsection{Author-constructed LangGraph Scope}
\label{sec:langgraph-validation}

Earlier LangGraph recovery-node and real-loop artifacts are retained only as
supplementary mechanism checks because the recovery node was authored for the
experiment rather than shipped as a default recovery primitive. They are not
pooled with the native Reflexion, AutoGen, or Aider results and do not support
the claim that LangGraph itself ships a vulnerable recovery loop.

\paragraph{RQ2 summary.}
The current evidence supports recovery-channel attack behavior across three
native framework paths with matched benign controls. Model heterogeneity is
large, and native path completion should be reported separately from ASR.
Author-constructed nodes and message-level screens remain supplementary.
