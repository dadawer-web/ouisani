## 1. 产品概述
AIOS 智能体工作流可视化编排器 — 一个面向 AIOS 操作系统的前端控制台，允许用户通过拖拽方式编排多智能体 Pub-Sub 工作流拓扑。
- 核心目标：让非技术用户也能直观地设计、编辑和部署 AIOS 工作流
- 目标用户：AIOS 系统管理员、智能体开发者

## 2. 核心功能

### 2.1 功能模块
1. **工作流画布**: React Flow 画布，支持拖拽、连线、缩放
2. **智能体节点**: 自定义卡片节点，包含角色/意图编辑、连接点
3. **侧边栏**: 添加智能体、工作流操作面板

### 2.2 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 工作流画布 | 画布区域 | React Flow 画布，深色背景，支持缩放和平移 |
| 工作流画布 | 智能体节点 | 卡片式节点，包含标题、Role 输入框、左右 Handle |
| 工作流画布 | 侧边栏 | 添加智能体按钮、工作流名称、部署按钮 |

## 3. 核心流程
用户点击"添加智能体" → 画布中央出现新节点 → 用户编辑 Role/Intent → 通过 Handle 连线建立 Pub-Sub 关系 → 点击"部署"将工作流提交到 AIOS 后端

```mermaid
flowchart LR
    "点击添加智能体" --> "画布添加节点"
    "画布添加节点" --> "编辑 Role/Intent"
    "编辑 Role/Intent" --> "拖拽连线建立 Pub-Sub"
    "拖拽连线建立 Pub-Sub" --> "点击部署到 AIOS"
```

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深色背景 (#0a0a0f) + 青色发光边框 (#00f0ff) + 紫色点缀 (#8b5cf6)
- 按钮风格：圆角、发光边框、hover 发光增强
- 字体：JetBrains Mono (代码风格) + 系统无衬线字体
- 布局风格：左侧边栏 + 右侧全屏画布
- 图标风格：lucide-react 线性图标

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 工作流画布 | 画布区域 | 深色背景、网格线、缩放控件 |
| 工作流画布 | 智能体节点 | 深色卡片、发光边框、Role 输入框、Handle 连接点 |
| 工作流画布 | 侧边栏 | 深色面板、添加按钮、工作流名称输入、部署按钮 |

### 4.3 响应式
桌面优先设计，画布占满可用空间
